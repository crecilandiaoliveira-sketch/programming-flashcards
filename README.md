# Programming Flashcards 📚

Um repositório com flashcards de programação para ajudar no estudo de conceitos fundamentais e avançados.

## 📖 Conteúdo

### 1. Conceitos Básicos
- Variáveis, tipos de dados, escopo
- Funções, callbacks e closures
- Hoisting e coerção de tipos

**Arquivo:** `flashcards/01-conceitos-basicos.md`

### 2. Arrays e Objetos
- Operações com arrays (map, filter, reduce)
- Objetos e propriedades
- Desestruturação e spread operator
- Imutabilidade

**Arquivo:** `flashcards/02-arrays-e-objetos.md`

### 3. Controle de Fluxo
- Condicionais (if/else, switch)
- Loops (for, while, do...while)
- Iteração com forEach, for...in, for...of

**Arquivo:** `flashcards/03-controle-de-fluxo.md`

### 4. Funções Avançadas
- Arrow Functions
- Parâmetros padrão
- Recursão
- Promises e async/await
- Tratamento de erros
- Funções de ordem superior

**Arquivo:** `flashcards/04-funcoes-avancadas.md`

### 5. Algoritmos e Estruturas de Dados
- Pilhas e filas
- Algoritmos de busca e ordenação
- Árvores e grafos
- DFS e BFS
- Programação dinâmica
- Notação Big O

**Arquivo:** `flashcards/05-algoritmos-e-estruturas.md`

## 🎯 Como usar

1. Leia a pergunta
2. Tente responder sem olhar a resposta
3. Verifique a resposta fornecida
4. Repita até dominar o conceito

## 📝 Formato

Cada flashcard segue o padrão:

```
## Pergunta?
**Resposta:** Resposta detalhada aqui
```
