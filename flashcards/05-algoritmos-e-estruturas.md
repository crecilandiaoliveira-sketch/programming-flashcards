# Algoritmos e Estruturas de Dados

## 1. O que é uma pilha (Stack)?
**Resposta:** Estrutura de dados LIFO (Last In, First Out) onde o último elemento inserido é o primeiro removido.

---

## 2. O que é uma fila (Queue)?
**Resposta:** Estrutura de dados FIFO (First In, First Out) onde o primeiro elemento inserido é o primeiro removido.

---

## 3. O que é um algoritmo de busca linear?
**Resposta:** Percorre sequencialmente cada elemento até encontrar o desejado. Complexidade: O(n).

---

## 4. O que é busca binária?
**Resposta:** Algoritmo que divide o array pela metade repetidamente. Apenas funciona com arrays ordenados. Complexidade: O(log n).

---

## 5. Qual é a diferença entre ordenação por bolha (Bubble Sort) e ordenação rápida (Quick Sort)?
**Resposta:**
- Bubble Sort: Simples, O(n²)
- Quick Sort: Mais eficiente, O(n log n) em média

---

## 6. O que é uma árvore binária?
**Resposta:** Estrutura de dados onde cada nó tem no máximo dois filhos (esquerdo e direito).

---

## 7. O que é um grafo?
**Resposta:** Estrutura composta por nós (vértices) conectados por arestas.

---

## 8. Qual é a diferença entre Depth-First Search (DFS) e Breadth-First Search (BFS)?
**Resposta:**
- DFS: Explora profundamente antes de retroceder (pilha)
- BFS: Explora por níveis (fila)

---

## 9. O que é programação dinâmica?
**Resposta:** Técnica que resolve problemas dividindo-os em subproblemas e armazenando resultados.

---

## 10. O que é notação Big O?
**Resposta:** Método para expressar a complexidade de tempo/espaço de um algoritmo.
