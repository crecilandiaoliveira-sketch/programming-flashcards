# Controle de Fluxo

## 1. O que é uma condicional `if/else`?
**Resposta:** É uma estrutura que executa diferentes blocos de código baseado em uma condição.

---

## 2. Qual é a diferença entre `if/else` e `switch`?
**Resposta:**
- `if/else`: Melhor para múltiplas condições complexas
- `switch`: Melhor para comparar um valor com várias opções

---

## 3. O que é um operador ternário?
**Resposta:** É uma forma condensada de `if/else`: `condicao ? valor_verdadeiro : valor_falso`

---

## 4. Como funciona um loop `for`?
**Resposta:** Executa um bloco de código repetidamente enquanto uma condição for verdadeira.

---

## 5. Qual é a diferença entre `for`, `while` e `do...while`?
**Resposta:**
- `for`: Número de iterações definido
- `while`: Executa enquanto a condição for true
- `do...while`: Executa pelo menos uma vez, depois verifica a condição

---

## 6. O que é um `break` em um loop?
**Resposta:** Comando que interrompe a execução do loop imediatamente.

---

## 7. O que é um `continue` em um loop?
**Resposta:** Comando que pula a iteração atual e passa para a próxima.

---

## 8. Como usar `forEach()` para iterar um array?
**Resposta:** `array.forEach((elemento, indice) => { })` executa uma função para cada elemento.

---

## 9. Qual é a diferença entre `for...in` e `for...of`?
**Resposta:**
- `for...in`: Itera sobre as chaves de um objeto
- `for...of`: Itera sobre os valores de um iterável

---

## 10. Como usar `switch` com casos múltiplos?
**Resposta:** Usando `case` para cada opção e `break` para sair, com `default` como padrão.
