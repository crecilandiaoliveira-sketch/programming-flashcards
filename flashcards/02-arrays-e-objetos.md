# Arrays e Objetos

## 1. O que é um array?
**Resposta:** É uma coleção ordenada de elementos do mesmo tipo, indexada a partir de 0.

---

## 2. Qual é a diferença entre `map()`, `filter()` e `reduce()`?
**Resposta:**
- `map()`: Transforma cada elemento e retorna um novo array
- `filter()`: Filtra elementos baseado em uma condição
- `reduce()`: Acumula valores em um único resultado

---

## 3. O que é um objeto em JavaScript?
**Resposta:** É uma coleção de pares chave-valor que representa uma entidade com propriedades e métodos.

---

## 4. Qual é a diferença entre propriedade e método?
**Resposta:**
- **Propriedade:** Um atributo que armazena um valor
- **Método:** Uma função associada ao objeto

---

## 5. Como desestruturar um objeto em JavaScript?
**Resposta:** Usando `const { propriedade } = objeto` para extrair valores específicas.

---

## 6. O que é spread operator (`...`)?
**Resposta:** Expande elementos de um array ou propriedades de um objeto.

---

## 7. Como clonar um array ou objeto?
**Resposta:**
- Array: `[...array]` ou `array.slice()`
- Objeto: `{ ...objeto }` ou `Object.assign({})`

---

## 8. O que é imutabilidade?
**Resposta:** É a prática de não modificar dados originais, criando novos dados em vez disso.

---

## 9. Qual é a diferença entre `push()` e `concat()`?
**Resposta:**
- `push()`: Modifica o array original
- `concat()`: Retorna um novo array sem modificar o original

---

## 10. Como verificar se uma variável é um array?
**Resposta:** Usando `Array.isArray(variavel)` ou `typeof variavel === 'object'`.
